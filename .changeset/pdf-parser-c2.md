New package `@platformcosmo/pdf`: a minimal hardened PDF parser for `pcosmo assets pdf …`. It lists pages, image placements (bbox and matrix) and text runs, extracts images (JPEG passthrough, everything else as PNG), opens Standard-handler files with an empty user password (RC4 and AES), repairs damaged cross-reference tables, and bounds every hostile input with a diagnostic (ingestion §4).
