features:
  - title: Claude writes the spec, code draws the diagram
    details: Claude only produces a small JSON spec. Layout, geometry, routing and animation are deterministic code, so the same spec always gives byte-identical SVG.
  - title: Works anywhere an image does
    details: The SVG animates inside img tags, inline, object and CSS backgrounds with no scripts, and respects reduced-motion and dark mode.
  - title: Cloud, AI and data center
    details: Semantic node types for compute, network, data, AI and CI/CD, plus parametric racks, rows, aisles and cabling for data-center halls.
  - title: Assemblies, figures and documents
    details: Parts that explode, implode and build; close-ups from a data-center hall down to a heat sink; manual figures and PDF step pictures replayed as animated builds.
  - title: Plugin or npm
    details: Install the Claude Code plugin, or run the same CLI with npx platformcosmo (Node.js 22.12 or newer). The engine is @platformcosmo/core.
  - title: Offline and safe
    details: The only network access is the icon download you ask for, restricted to https and public addresses. Icons are sanitized, text is escaped, and output has no external references.
