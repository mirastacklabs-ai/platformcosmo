# Icon licensing research (2026-11-18)

Primary sources fetched 2026-11-18. Not legal advice.

| Pack                                                | Terms                                                                                                                                                                                                                                                     | Version                | Decision                                                                                          |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------- |
| Lucide                                              | ISC, **plus MIT** (Cole Bemis) for ~190 Feather-derived icons listed in the LICENSE                                                                                                                                                                       | `lucide-static` 1.75.0 | Bundle; ship both notices                                                                         |
| Kubernetes icons (`kubernetes/community/icons/svg`) | Apache-2.0 **or** CC-BY-4.0 (choice); K8s logo is an LF trademark                                                                                                                                                                                         | pin a commit SHA       | Bundle under Apache-2.0; LF trademark note                                                        |
| CNCF artwork (`cncf/artwork`)                       | No copyright license; "made available under the Linux Foundation trademark usage guidelines"; marks must not be altered                                                                                                                                   | —                      | **Do not bundle**; optional fetched pack                                                          |
| Simple Icons                                        | Repo CC0-1.0, but per-icon licenses vary: 3,472 icons, 225 with other licenses (incl. NC/ND/GPL/custom), most with no license field ("absence does not imply unlicensed")                                                                                 | `simple-icons` 16.38.0 | Bundle **only** icons whose `license` is CC0-1.0/MIT/Apache-2.0 (keep notices); exclude others    |
| AWS Architecture Icons                              | "We allow customers and partners to use these toolkits and assets to create architecture diagrams." No redistribution text; zip URL is date+hash, changes quarterly. Landing: https://aws.amazon.com/architecture/icons/                                  | Q3 2026 zip            | Fetch on user machine; resolve the current zip from the landing page or a pinned URL with SHA-256 |
| Azure Architecture Icons                            | "use … in architectural diagrams, training materials, or documentation … copy, distribute, and display the icons only for the permitted use". Download requires agreeing. Zip: https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V25.zip | V25                    | Fetch; show terms; require `--accept-terms`                                                       |
| Google Cloud icons                                  | No terms found on https://cloud.google.com/icons; zips under `https://services.google.com/fh/files/misc/` (`core-products-icons.zip`, `category-icons.zip`)                                                                                               | unversioned            | Fetch; show "check Google's terms" notice; never redistribute                                     |

Rendered diagrams that contain provider icons are "use in diagrams" (allowed by AWS and Azure text); the gallery may commit rendered provider examples, never the packs themselves.
