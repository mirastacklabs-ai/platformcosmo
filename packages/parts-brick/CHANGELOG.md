# @platformcosmo/parts-brick

## 0.1.0

### Minor Changes

- 2d486b9: New `@platformcosmo/parts-brick`: the five `brick:` part shapes (brick, plate, tile, round, slope) in stud units, with a stud grid on top (studs extend `bounds` but not `depthBox`), a generic colour palette, `readParams` did-you-mean, and `checkBrickPlacement` for the `brick/off-grid` warning. Core now also exports `studGrid`, `STUD_DIAMETER`, `STUD_HEIGHT` and `partPrimitiveSilhouette`.
